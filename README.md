# Hi, I'm Haka 👋

I build practical software products, with a focus on architecture, engineering quality, and AI-assisted development.

My background is in backend engineering. Today I work across stacks, choosing technologies to fit the problem rather than defining my work by a programming language.

## Engineering beyond programming languages

I believe great software starts with engineering thinking, not with a programming language.

Clear requirements, thoughtful architecture, security, maintainability, and attention to detail matter more than the syntax used to implement them.

AI helps accelerate implementation, but it doesn't replace engineering judgment. I care about explicit boundaries, reproducible builds, meaningful tests, and independent reviews.

> **The language is a tool. Engineering is the foundation.**
